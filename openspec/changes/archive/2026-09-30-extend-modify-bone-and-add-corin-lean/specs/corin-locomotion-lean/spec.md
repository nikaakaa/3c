## Purpose

定义 Corin 地面跑动转弯时的身体侧倾与回正行为，使用动画图中的运动派生参数和通用骨骼变换完成正式表现，同时保持现有跑步动画、动作覆盖、脚部求解和输出路径的业务边界。

## ADDED Requirements

### Requirement: 跑动转弯必须产生方向正确的连续侧倾

Corin 在地面跑动且实际水平运动方向发生转弯时 MUST向弯内侧倾。侧倾强度 MUST受实际转向速度、水平速度权重和显式最大角度约束；同等转向速度下，低于满侧倾速度的慢速运动 MUST得到较小倾角。直行、原地转向、零速、离地和不适用状态 MUST不持续产生侧倾目标。

#### Scenario: 向左右转弯
- **WHEN** Corin 分别执行持续左转跑动和右转跑动
- **THEN** 身体 MUST分别向左和向右倾斜，幅度不超过作者上限
- **AND** 跑步动画 MUST继续播放，角色位置和碰撞 MUST不因侧倾被改写

#### Scenario: 直线持续跑动
- **WHEN** Corin 保持非零跑速但实际运动方向不再变化
- **THEN** 侧倾目标 MUST回到零，身体按配置逐渐回正
- **AND** MUST不因前向速度持续非零而永久前倾或侧倾

### Requirement: 侧倾必须平滑变化并拥有明确重置行为

侧倾与回正 MUST使用显式时间参数和正式表现帧时间，换边 MUST连续经过零。历史 MUST属于当前动画实例；新实例、Reset、身体不连续和图替换后的首帧 MUST不由旧方向计算虚假侧倾。低速无有效方向或完全反向导致左右无法唯一确定时 MUST将目标设为零，并遵守既有折返流程。

#### Scenario: 左转立即改为右转
- **WHEN** 已有左倾的跑动改变为右转
- **THEN** 侧倾 MUST先连续回正再向右倾，不直接跳到相反最大角度

#### Scenario: 角色瞬移或重置
- **WHEN** 正式输入报告身体不连续或实例重置
- **THEN** lean 历史 MUST清空，首帧输出中性侧倾，再从后续连续运动建立结果

### Requirement: 侧倾必须由正式动画图驱动通用骨骼能力

运动到倾角的公式、参数、平滑和历史 MUST可在 Corin 正式动画更新图中追踪；输出 MUST以精确旋转类型交给通用骨骼变换。Corin 正式跑动状态 MUST实际消费该输出。系统 MUST不增加专用 Lean 底层节点、旧姿态样本修正资源、MonoBehaviour 骨骼修改或第二份倾角状态。

#### Scenario: 作者查看并调整侧倾
- **WHEN** 作者打开 Corin 正式动画更新图与跑动状态图
- **THEN** MUST能找到输入事实、侧倾计算、调参、旋转输出和实际骨骼消费者
- **AND** 修改参数 MUST经过现有作者入口，不要求更改运行代码或另开专用编辑器

### Requirement: 有限动作和折返必须保持原有表现所有权

侧倾 MUST仅在配置的 Run Start 和 Run Loop 姿势分支施加，之后继续原状态混合和动作覆盖。Idle、Walk、Run End、TurnBack MUST不施加该修正；状态和动作过渡 MUST继续按原混合权重处理。完整全身动作覆盖时 MUST不残留底层跑动侧倾，既有折返朝向修正 MUST不被更改。

#### Scenario: 跑动中进入攻击或闪避
- **WHEN** 原动作槽逐渐覆盖跑动姿势
- **THEN** 跑动侧倾 MUST随底层姿势权重退出，完整覆盖时由原动作姿势决定身体表现
- **AND** MUST不在最终动作姿势后再无条件施加 lean

#### Scenario: 跑动退出或进入折返
- **WHEN** Corin 从跑动状态切换到停步或折返
- **THEN** 已有状态混合 MUST使结果过渡到未施加 lean 的目标姿势
- **AND** 原状态条件、动画来源、播放时间与折返算法 MUST保持原合同

### Requirement: 侧倾必须保留唯一脚部求解与最终输出

修正后的姿势 MUST继续进入既有 Foot Placement、Goal Assembly、FullBodyIK 与最终输出。每帧这些阶段的 owner 和执行次数 MUST保持现行约束，不创建独立脚目标、第二求解器或图外写回。骨骼和虚拟骨骼 MUST形成一致姿势后再由下游消费。

#### Scenario: 跑动侧倾与脚部求解同时生效
- **WHEN** Corin 在有侧倾的跑动帧执行脚部约束
- **THEN** MUST只经过原有一次脚部事务和正式最终写入
- **AND** 不得为了完成 lean 自动重建脚部校准、改变脚部算法或绕过原校验

### Requirement: 参数来源必须可区分且完整接入正式内容

侧倾参数 MUST区分 dump 中实际读取的值、尚未确认的语义和本项目选择的初始调参；没有完整证据时 MUST不宣称与原游戏数值一致。交付 MUST同时包含通用能力、Corin 正式图引用、实际参数生产和实际姿势消费，不能以节点存在、样本文件或编译成功代替角色接入。

#### Scenario: 采用原游戏配置作为初始参考
- **WHEN** 作者使用 dump 中的默认响应时间和映射表输出设置本项目参数
- **THEN** 来源说明 MUST保留配置身份和已知限制，不把未知输入单位或 999 字段值直接当作 Corin 的有效最大倾角
- **AND** 参数 MUST通过同一正式作者图可读可调
