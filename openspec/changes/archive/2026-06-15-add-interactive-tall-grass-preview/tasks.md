## 1. 规格和边界
- [x] 1.1 确认该能力只做场景高草丛预览，不接入潜行、敌人感知或战斗逻辑。
- [x] 1.2 确认不新增角色控制器、独立相机或第三方植被系统。
- [x] 1.3 确认第一版只支持单交互源，多交互源后续另起变更。

- [x] 9.8 移出交互源，确认草片恢复到风摆状态。
