## Purpose

定义角色静态姿态修正样本的制作、装配、驱动和求值行为，使动画取帧与直接骨骼编辑产生同一种正式数据，并通过现有 PoseGraph 表达运动造型与骨骼方向修正，同时保持角色资源、末端约束和最终输出的明确边界。

## ADDED Requirements

### Requirement: 两种制作入口必须产生同一种静态修正样本

系统 MUST支持从精确动画素材帧提取和直接编辑骨骼目标两种制作方式，并将结果保存为同一种正式样本数据。样本集 MUST明确中性参考、二维轴单位与有效域、受影响骨骼和稳定样本身份；每个样本 MUST完整覆盖同一受影响骨骼集合。静态样本 MUST不拥有 Player、播放时钟、Foot Analysis、Action Curve 或运行中的资产查找。

#### Scenario: 素材提取后继续手动调整

- **WHEN** 作者将指定动画帧提取为一个方向样本，再调整其中一个骨骼
- **THEN** 系统 MUST修改同一 SampleId 的正式目标姿态
- **AND** 运行时 MUST只消费最终编译样本，不按制作方式选择另一套求值流程

#### Scenario: 缺少目标骨骼

- **WHEN** 某个样本没有完整覆盖样本集声明的受影响骨骼
- **THEN** 正式校验 MUST定位样本和缺失骨骼并拒绝保存或发布
- **AND** MUST不从上一份样本或上一帧 Pose 补齐

### Requirement: 动画提取必须是显式且原子的快照操作

动画提取 MUST读取作者指定的 Clip、合法时间和角色 Rig，形成完整候选后一次提交正式样本 Mutation。系统 MUST保持原 Clip 的骨骼曲线、注册表现曲线、事件与导入设置不变。样本提取出处 MUST不作为运行中的活动资源依赖；源素材后续变化 MUST不自动改写快照。重新提取 MUST显式选择目标样本并保留其稳定身份。

#### Scenario: 原素材发生变化

- **WHEN** 已提取样本的原动画骨骼曲线被修改
- **THEN** 已保存样本 MUST保持原值，直到作者显式重新提取
- **AND** 系统 MUST不在选中、刷新或播放时重采样并覆盖作者手调结果

#### Scenario: 候选生成后输入过期

- **WHEN** 取帧候选生成后源 Clip 或目标样本 revision 发生变化
- **THEN** 提交 MUST拒绝该过期候选并定位变化来源
- **AND** MUST不保存部分骨骼或改变原样本

### Requirement: 参数驱动与骨骼方向驱动必须具有独立合同

系统 MUST提供显式二维参数驱动和显式骨骼方向驱动两种节点。参数驱动 MUST读取类型和单位匹配的图参数；骨骼方向驱动 MUST读取修改前输入姿态中源骨骼相对参考骨骼的方向，并按中性标定生成连续域内的 yaw/pitch。参考骨骼、方向轴与有效角度域 MUST明确。两者 MUST只输出 Component Pose，不自动切换驱动来源，也不消费原始按键、可变 Gameplay 地址或 Foot 私有状态。

#### Scenario: 角色转身后继续向自身前方移动

- **WHEN** 角色世界朝向改变但角色局部前向速度和修正配置相同
- **THEN** 参数驱动 MUST选出相同的样本权重
- **AND** MUST不因世界 XZ 方向变化把前倾变成侧倾

#### Scenario: IK 改变源骨骼方向

- **WHEN** 骨骼方向节点放在 IK 之后并消费其输出姿态
- **THEN** 驱动 MUST来自该输入姿态的实际骨骼方向
- **AND** MUST不以角色速度或上一次骨骼测量替代

#### Scenario: 轴单位不匹配

- **WHEN** 角度单位的骨骼方向驱动绑定到速度单位的样本接口
- **THEN** Build MUST拒绝该绑定并报告两侧单位

#### Scenario: 输入骨骼方向无法唯一测量

- **WHEN** 本帧方向位于声明角度表达的歧义分支或极点
- **THEN** 节点 MUST产生明确Invalid，不自动换轴、使用中性方向或沿用上一帧结果

### Requirement: 修正必须相对中性姿态施加到本帧输入

系统 MUST以样本目标相对中性参考的局部位置差、旋转差和缩放比施加到本帧输入姿态，保留输入动画的其它变化。位于零坐标的中性样本 MUST与中性参考一致；有效零权重 MUST产生恒等修正。全部骨骼基值和驱动测量 MUST来自修改前输入，更新后 MUST按正式 Rig 依赖传播到受影响后代及 Virtual Bone。节点 MUST不累积修改上一帧最终 Transform。

#### Scenario: 连续多帧保持同一输入

- **WHEN** 输入 Pose、驱动参数和权重在连续帧中完全相同
- **THEN** 修正结果 MUST保持相同而不逐帧漂移

#### Scenario: 同时修改父骨骼和子骨骼

- **WHEN** 一个样本同时影响骨盆与其子骨骼
- **THEN** 两个局部修正 MUST各从原输入基值计算并按层级传播
- **AND** 子骨骼 MUST不重复吸收父骨骼已施加的差值

#### Scenario: 权重为零但输入无效

- **WHEN** 修正节点权重为零且必要输入 Pose 为 Invalid
- **THEN** 输出 MUST保持 Invalid，不能以中性或旧姿态伪装为有效结果

### Requirement: 样本覆盖与骨骼引用必须在发布前有效

样本集 MUST具有非退化二维覆盖，坐标、轴范围、姿态值和旋转 MUST有限且合法，局部缩放 MUST为正。重复身份、重复坐标、错误 Rig、未知骨骼、不可写 Virtual Bone 和越过方向歧义边界的标定 MUST使正式校验失败。声明域内的有限输入 MUST按同一显式限域和权重规则产生有效结果，不允许运行时默认样本或静默改用另一插值规则。

#### Scenario: 样本空间退化

- **WHEN** 二维样本全部共线或中性样本缺失
- **THEN** Build MUST定位样本集并拒绝发布

#### Scenario: 角色 Rig 被替换

- **WHEN** 样本或骨骼标定与 Profile 当前 Rig 不匹配
- **THEN** 系统 MUST要求显式重新绑定或重新制作，不按骨骼显示名猜测映射

### Requirement: 静态修正必须保留姿态之外的数据含义

节点 MUST沿输入透传参数、曲线、source lineage 和可用性，只修改声明的骨骼姿态。它 MUST不改变 Foot Weight、Phase、Action admission、Body 位移、WorldResidual、Goal 内容或求解器内部历史。节点输出 MUST进入现有 PoseGraph 最终发布，不直接写物理骨骼。

#### Scenario: 修正跑动的骨盆造型

- **WHEN** 作者通过样本改变跑动输入的骨盆局部姿态
- **THEN** Foot 与 Phase 控制数据 MUST继续保持原输入含义
- **AND** 后续 Foot/IK 只能通过正式输入 Pose 感知该变化

### Requirement: 作者必须能够编辑样本并区分静态视图与完整效果观察

作者工作区 MUST提供中性参考、二维样本点、受影响骨骼、目标姿态、取帧、重提取、删除和撤销操作，并显示当前样本权重及精确绑定。中性参考变更 MUST作为整集重标定保持每个样本的局部位置差、旋转差和缩放比，并显示骨骼方向坐标变化、重新校验覆盖；不得静默改变全部方向含义或承诺整个输入域的插值权重不变。静态资产视图 MUST不推进完整角色；跑动和落脚效果观察 MUST使用正式场景 Actor 及其 PoseGraph 结果，不建立另一套预览执行链。

#### Scenario: 静态编辑没有运行场景

- **WHEN** 作者在未运行角色时调整样本骨骼
- **THEN** 工作区 MUST允许编辑并保存静态样本，同时明确完整角色效果尚未运行
- **AND** MUST不显示伪造的 Foot/IK 结果

#### Scenario: 修改中性参考

- **WHEN** 作者更换样本集的中性姿态
- **THEN** 系统 MUST作为一次整集操作更新样本与标定，并保持每个样本的局部骨骼修正差值
- **AND** 撤销 MUST恢复整个样本集而不只恢复参考字段

#### Scenario: 样本结构改变后观察角色

- **WHEN** 样本骨骼或姿态数据改变但正式 Projection 尚未重新发布
- **THEN** 工作区 MUST显示需要构建，不能静默热换运行页或声称新样本已生效

### Requirement: 角色示例装配必须使用完整正式链路

本能力的内容装配 MUST只覆盖已授权的稳定 Corin，并明确样本、Slot、Binding、状态适用、权重和 IK 关系。生成产物 MUST通过精确 Definition 的正式 Build 发布；仅存在类型、菜单节点或未绑定样本 MUST不视为已接入。系统 MUST不借此迁移 TrainingEnemy 或吸收其它 Foot/IK 变更。

#### Scenario: 节点没有角色绑定

- **WHEN** Corin 图引用修正 Slot 而 Profile 没有唯一匹配 Binding
- **THEN** Build MUST失败并定位 Slot，不创建空样本透传配置
