## ADDED Requirements

### Requirement: 技能作者代码整理必须保留端口与求值语义

值端口的类型、稳定身份、输入来源、默认值、转换规则、连接关系和求值依赖 MUST 按现有正式链保留。原生端口、作者 descriptor 与编译绑定存在 MUST 不被视为旧节点全部能力等价迁移的证明。此次整理 MUST 不改变求值顺序、重复读取行为、短路规则、变量可见性或运行实例隔离。

#### Scenario: 原生值边进入编译内容

- **WHEN** 移动作者端口定义及其编译消费者
- **THEN** Value 边的源/目标操作与端口身份以及常量绑定 MUST 保持
- **AND** Fixed/Float32 的现有输入绑定与递归求值 MUST 不因文件归位改变

#### Scenario: 发现求值行为差异

- **WHEN** 核对发现旧节点短路而编译链提前求值，或某类型缺少编译映射
- **THEN** MUST 记录具体节点、条件和行为差异，不宣称等价或据此删除旧实现
- **AND** 修复和脏缓存等优化 MUST 经用户明确范围决定，不自动并入文件整理
