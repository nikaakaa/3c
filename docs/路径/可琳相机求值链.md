# 可琳相机求值链

更新日期：2026-10-01。本文描述当前正式求值路径；完整相机复刻仍未完成。

## 输入与输出

Timeline／Ability 通过 `CharacterCameraDomainRuntime` 提供相机请求。相机域从共享表现帧取得角色位置、朝向、鼠标／摇杆输入与时钟，从绑定 Rig 取得真实输出宽高，再构造 `CameraFrameInput`。Profile 经 `CharacterCameraProjectionBuilder.Build` 生成唯一的运行投影。

每帧顺序为：

1. `CameraEffectEvaluator.PrepareFrame` 接纳请求与退出，准备本帧效果实例。
2. `CharacterCameraSequenceEvaluator.Evaluate` 更新输入轴；`CameraStretchPitchRuntime` 更新归一化仰角；`CharacterCameraFramePlanner` 用同一轨道求位置与旋转。
3. `CameraEffectEvaluator.ApplyFraming` 依次应用 Override、Zoom、Stretch，得到本帧半径、FOV、Pivot 偏移及滚转。
4. `CameraWorldBasicHistory.Apply` 用该结果计算跟随阻尼与构图。上一帧构图修正由既有 `m_Current` 和 `m_PreviousOffset` 还原，按 `WithFraming` 换算到当前半径／FOV，再继续累积；不增加第二份构图缓存。
5. 构图先对死区越界修正执行 `CompositionDamping`，再约束软区外框，保证外框修正不被再次阻尼。
6. `CameraEffectEvaluator.Resolve` 应用 Shake、Shot，记录贡献并推进每个实例的时钟一次。震动不进入 Delay 历史。
7. `CameraFramePlan.WithPitchClamped`、环境约束、`CinemachineCameraRigAdapter.Apply` 完成最终写回。

`CameraFramePlan.Pitch` 与 Rig 基准使用朝上为正的方向角；Unity 欧拉 X 的符号相反。未越界时限位直接保留原计划；越界时使用负的方向角重建欧拉 X，避免每次限位翻转镜头。

## 本次行为变化

静止偏心构图会保留已经完成的修正，不再逐帧回到原始轨道偏移。Zoom／Stretch 的当前 FOV 和半径进入同一份 Delay 历史，再交给震动与 Rig。限位不再翻转处于合法范围内的 Pitch。

本批没有改动或删除相机资源，没有改变震动的波形、频率、振幅、Base 仲裁或 Timeline 激活身份。新增帧路径只使用既有预分配容器与值类型；没有新增托管分配。实际 GC 未采集。

## 剩余边界

默认轨道 Follow／Aim 偏移、完整 Delay 模式资格及旋转通道、Zoom／Stretch 剩余生命周期仍未全部闭合。震动独立倍率聚合器、区域静默、结算演出 Base 保持、取消优先级及命中强度需要正式业务生产者；不能接到普通攻击或 E Hold 上替代这些业务。
