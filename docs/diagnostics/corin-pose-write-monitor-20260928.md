# 角色骨骼写入后的不匹配日志

## 使用

按用户要求直接输出 `[PoseWriteMismatch]` Warning，不需要开启采样或按标记。Editor 和 Development Build 默认随角色装配启用；正式非开发 Player 不编译此检查。

角色最终姿态写入后，保存根节点、骨盆、左右髋膝踝脚趾共 13 个节点的局部位置、旋转、缩放。每个 Game 相机的 URP 渲染前后，与同一 Unity 帧的快照比较。Gameplay Lab 角色可能没有自带相机，所以直接观察实际 Game 相机的渲染事件，不依赖角色相机装配。

日志含角色 ID、Unity 帧号、表现帧号、姿态完成标识、渲染阶段、相机、变化节点数量、首个变化骨骼，以及预期值、实际值和最大差值。容差为位置 0.00001 米、旋转 0.1 度、缩放 0.00001，用于过滤数值噪声。连续帧持续不匹配只报首次，至少间隔一个完整正常帧后再次出现会重新记录。

正常路径复用装配时分配的数组，不格式化字符串；异常日志会产生字符串分配。没有运行时 GC 实测。重置、新表现帧开始时失效旧快照，角色销毁时注销渲染回调。

这条日志只证明写入后的骨骼被改动，不把正常动画速度或帧间换脚当作错误；没有日志也不能证明整个动画链正确。若拉扯出现而没有日志，继续沿源姿态和过渡链查。
