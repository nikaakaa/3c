# 技能运行数据重建

Corin 的正式入口是 `Tools/3C/Internal/Republish Corin Ability Data`。菜单只选择 `CorinCharacterPipelineDefinition` 与既有 Abilities 输出目录，调用 `GameplayAbilityExecutionDataAssetPublisher.PublishDefinition`。

作者输入来自 Definition 的 AbilityGrants 和各技能图。发布器与编译器确认这些输入，生成 Fixed / Float32 运行产物、保持资产身份并更新 Definition 绑定。角色启动从 Definition 加载这些产物，交给 `FixedGameplayAbilityExecutionInstallationSet` 装配；黑板声明由 `ProgramCatalogRuntimeIndex.BindBlackboardDeclarations` 绑定到状态槽。

技能 Build 不依赖整个角色的动画、Pose 或相机配置校验。这些配置由各自的装配和构建入口负责。菜单已删除此前调用 `CollectConfigurationErrors` 的全域前置检查，避免独立的动画资源错误阻止技能运行数据重建；技能发布器原有的输入检查仍是正式边界。

运行数据契约变化后必须重建原产物。运行时不从 Setter、变量名字或当前作者图反推旧绑定，也不忽略缺失声明。菜单的 attempted 返回及客户端等待超时不作为发布证据，应读取已生成的产物并检查实际装配结果。
