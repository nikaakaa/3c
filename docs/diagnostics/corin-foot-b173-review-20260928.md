## 4. 硬下界会引入另一种突变风险

本包有 9 条安全下界夹取，最大 0.136913m（15582 右脚 Swing）。这表示在平滑输出之后又补了最多 13.69cm 的高度，不等于已经验证同等幅度的最终骨骼跳变，但它是必须独立追踪的突变来源，不能把最终 clearance 合格当作动作平滑通过。

## 下一步应处理的具体责任

1. 接触目标必须说明脚跟/脚尖究竟支撑在哪一级，并在最终姿态下成立；只保护中点锚点不足以防止跨级穿透。
2. 包络末端的毫米级水平跨度/整级高度下降必须和落地时间一并检查。当前中点投影不保证动画事件到来前走完末段。
3. 末级高度速度限制仍能让正确目标无法按时到达，不能在上述地形目标未正确前单独加速。
4. Releasing 的支撑退出条件与几何约束仍未闭合；不能一刀切对所有阶段使用未来落点下界，也不能把锚点更新全部交给平滑。
