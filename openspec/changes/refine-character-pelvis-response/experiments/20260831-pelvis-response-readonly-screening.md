455个正式求值帧中201个请求变化超过0.1毫米；278帧从+293.375毫米变为−5.659毫米，说明它不是等价代数改写。模型世界大步33→31、Correction大步28→19，但负偏移积分0.338134→0.361398，平地均值−18.565→−19.539毫米，移动均值−15.355→−17.170毫米。原774帧中负偏移220→292；由于新目标可能已负，不能把新增72帧全叫原目标下的回正迟滞。

该模型没有新增完成点。它减少部分大步但加重当前关注的下压，因此没有准入实施。现行delta还明确要求两份最低高度分别取值，不能暗换公式。若以后重开，必须说明目标业务为何改变，并继续检查平地下压，不能只挑大步计数。

## 新闭合的ZZZ普通历史核

以下是静态证据，不是模型效果背书。文件为D:/ZZZ_Dump/PIK分析包/disasm_exact/pik_core/function_171D9EE0_171DAB5C.asm。

令p=旧190、m=旧194、q=97B0／9AF0选出的候选、dt=this124。252未旁路且走普通路径时：

```text
trial = q
if A0:
    if abs(q-p) > A4:
        increment = (((q-p) * A8) * dt) * 60
        m = (m + increment) * powf(AC, dt * 60)
        trial = p + (m * dt) * 60
    else:
        m = 0
rate = (199 != 0) ? 2A8 : 2AC
limited = p + sign(trial-p) * min(abs((trial-p)/dt), rate) * dt
```

9FCE–A0E2是历史分支；A041调用E52EA0；A04D先写194；A0E2–A18C才限制本次变化。有限正dt下最后一式在实数中等价于p＋clamp(trial−p,−rate×dt,+rate×dt)。194是限速前的历史，不是最后实际位移除dt；A0关闭不等于显式清194。小误差清的是历史，trial仍是q，不是位置清零或保持旧p。

74份既有活跃Corin实例原始切片（D:/ZZZ_Dump/output/pik_instance_probe_20260829_192558.json，实例0x7002134F000）给出A0=1，A4约0.02，A8=AC约0.4，2A8约0.5、2AC约0.8。不是每脚1.8／1.5，也不是其它未活跃实例的0.65／0.9。在理想dt=1/60时可简写为m_new=0.4*m_old+0.16*(q−p)，trial=p+m_new，再限本次变化；不能把这个简式用于任意帧率。

## 本轮留下的可复用经验

- 不能把只换目标MIN、只加限速与整个ZZZ普通核合并称为“试过ZZZ了”；三者并非一个实验。
- 负偏移变少、世界大步变少和目标允许回零时的驻留必须并列；后者的资格不能跟随候选偷偷变化。
- 小误差分支改变完成时机后，冻结旧后继输入的模型不再代表完整闭环。
- 真实硬边界仍掌握最终位置时，任何前置响应模型的收益都要与最后夹紧分开；不能把最终Clamp后的位移误报成响应遵守了有限速度。
- 下一次若实施，只能先形成明确输入／状态／退出合同并独立Replay，不把本记录数字贴成运行验收。
